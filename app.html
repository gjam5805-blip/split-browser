🖥 Multi Screen app

Ek click me 2 se 12 tak asli Chrome windows, screen pe grid me apne aap set. Har window me YouTube (recommendations, login, video), Netflix, sab kuch.

⬇ Multi Screen download (Windows + Mac)
Poora ChromeTabs aur address bar wali normal windows.
Patli windows10–12 screens ke liye, address bar ke bina.
Tumhara profileJis Chrome profile me login ho, wahi chuno.

Windows laptop pe (~2 min)

  1. Upar wala zip download karo, right-click → Extract All.
  2. Folder me Install Multi Screen (Windows).bat pe double-click. Python na ho toh khud install karega.
  3. Desktop pe Multi Screen icon aa jayega. Kholo → number dabao.

Mac pe (~3 min)

  1. Zip download karo, double-click se khul jayega.
  2. Install Multi Screen (Mac).command pe right-click → Open → Open (pehli baar Mac poochta hai).
  3. Mac poochega "control Google Chrome?" → OK. Desktop pe Multi Screen aa jayega.

Tips: "Phir se set karo" se bikhri windows wapas grid me. "Sab band karo" se sirf Multi Screen wali windows band hoti hain, tumhari baaki Chrome nahi. Do screen (projector extend) ho toh app me "Kis screen pe" ka option aata hai.
