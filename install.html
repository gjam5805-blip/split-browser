⚡ Asli YouTube: extension lagao

Har laptop pe ek baar, ~2 minute. Iske baad Multi Screen ki har screen me asli youtube.com (home, recommendations, sab), Instagram, Facebook bhi khulenge.

  1. Extension download karo ⬇ multiscreen-helper.zip
    Download hone ke baad zip pe right-click → Extract All (Mac pe bas double-click). Ek folder banega MultiScreenHelper. Isse aisi jagah rakho jahan se delete na ho (jaise Documents).
  2. Chrome ka extensions page kholo Nayi tab me ye likho aur Enter: chrome://extensions
    Microsoft Edge me: edge://extensions
  3. "Developer mode" ON karo
    Page ke upar right side me ek switch hai (Edge me left side, neeche). Use ON kar do.
  4. "Load unpacked" dabao aur folder chuno
    Wahi MultiScreenHelper folder select karo jisme manifest.json hai, aur Select Folder dabao. "Multi Screen Helper" ka card aa jayega.
  5. Multi Screen page refresh karo ↩ Multi Screen kholo
    Upar ✅ Asli YouTube ON dikhega. Ab kisi screen me youtube likh ke Enter dabao.
Chrome install ke time bol sakta hai ki extension "sab websites ka data padh aur badal sakta hai". Ye isliye kyunki YouTube jaisi har site ki "mujhe andar mat kholo" wali line hatani padti hai. Extension ye sirf Multi Screen wale tab ke andar ki screens ke liye karta hai. Baaki tabs, aur koi data, wo chhoota bhi nahi.
